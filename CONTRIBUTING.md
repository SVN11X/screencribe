# Contribuir

1. Crea una rama desde `main`.
2. Mantén el frontend sin dependencias de compilación.
3. No agregues claves ni tokens al repositorio.
4. Ejecuta `node --check` sobre los archivos JavaScript.
5. Ejecuta `python -m compileall backend/app` para validar sintaxis.
6. Describe claramente los cambios y sus implicancias de privacidad.
