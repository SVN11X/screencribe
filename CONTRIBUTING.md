# Contribuir

1. Usa Node.js 22 o superior.
2. Ejecuta `npm ci`.
3. Trabaja en una rama separada.
4. Agrega pruebas para lógica reutilizable.
5. Ejecuta `npm run format:check`, `npm run check` y `npm run build`.
6. Prueba manualmente captura, conversión y WebGPU en Chrome o Edge.
7. No agregues grabaciones reales, datos personales, pesos del modelo ni secretos al repositorio.
8. No cambies el modelo o la cuantización sin documentar impacto en descarga, memoria y precisión.
