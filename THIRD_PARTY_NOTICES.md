# Avisos de terceros

Esta entrega no incluye librerías de terceros en la página. Se retiraron el wrapper, el núcleo WebAssembly, las fuentes y las licencias adjuntas de FFmpeg porque ya no se distribuyen con el sitio.

El código propio conserva la licencia MIT de `LICENSE`. Los componentes internos del navegador y del sistema operativo mantienen sus propias condiciones; Screencribe los utiliza mediante las APIs web y no los distribuye.

Playwright y FFmpeg/FFprobe nativos se usan únicamente para pruebas de desarrollo/CI. No se publican con la página ni se solicitan a visitantes.
