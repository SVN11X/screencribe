# Privacidad

- GitHub Pages solo entrega archivos estáticos de la aplicación.
- La grabación se mantiene en la memoria del navegador hasta que el usuario la descarga o reemplaza.
- Las conversiones WebM, MP4 y MP3 se ejecutan localmente.
- El audio se decodifica y transcribe localmente con WebGPU.
- El audio y el texto no se envían a una API de transcripción.
- Los archivos del modelo se descargan desde Hugging Face.
- La aplicación no incluye analítica, cuentas, cookies publicitarias ni almacenamiento remoto.
- La configuración básica se guarda en `localStorage` del navegador.
- El navegador puede conservar el modelo en su caché.

No grabes a personas sin informarles y sin la autorización exigida por la legislación aplicable. Evita tratar datos sensibles en equipos compartidos y elimina descargas o cachés cuando sea necesario.
